# RecallAI — DevBrain

> Your Developer Second Brain. A **local, private RAG system** that indexes your dev work
> (Git, files, Confluence, ValueEdge…) and answers questions in plain English — **with sources**.

## Status
Planning complete. Building **Phase 1 (MVP)**: Git + local files → ask questions → answers with citations.
Runs 100% locally (Ollama) — company data never leaves your machine.
